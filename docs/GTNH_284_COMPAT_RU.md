# SMOG 0.1.0 — совместимость с GTNH 2.8.4

Изменения ограничены проверками совместимости и build-зависимостью. **Не оптимизация и не изменение геометрии/физики или алгоритма Mixins.**

## Что вызывало отказ в запуске

1. Исходный `@Mod(dependencies=...)` требовал **UniMixins >=0.3.1**, но в GTNH 2.8.4 установлен **0.1.23**. На этапе FML это обязательное ограничение блокировало старт ещё до применения Mixins.
2. В `SmogMod.preInit()` жестко сравнивалась версия FML-мода `gregtech` с `5.09.54.229`. В GTNH 2.8.4 фактический JAR GT5U **5.09.51.482**, а мод `gregtech` может сообщать версию `MC1710`. Реальную версию GT5U предоставляет `gregtech_nh`.

## Исправления

- `@Mod`: `required-after:unimixins@[0.1.23,)`.
- `preInit`: проверка версии мода `gregtech_nh` против `5.09.51.482`, вместо сравнения `gregtech` с `5.09.54.229`.
- `dependencies.gradle`: GT5U `5.09.51.482:dev` для дальнейшей пересборки из исходников.
- `minVersion: 0.8.5` в Mixin JSON **не изменён**: в UniMixins 0.1.23 есть Mixin 0.8.7; MixinExtras 0.5.0 поддерживает текущие инъекции.
- Не изменены классы инъекций, `law4`, чекпоинты, порядок расчёта и маршруты выбросов.

## О происхождении предлагаемого runtime JAR

JAR выпущен **путём точечной правки четырёх констант constant pool в исходном Java 8 JAR**, а не полным Gradle rebuild. Способ повторяемый: `python3 verification/repack_gtnh_284.py ORIGINAL.jar PATCHED.jar`. Во всех файлах JAR, кроме `org/smogmod/SmogMod.class`, байты совпадают с исходным JAR. Классовая версия осталась 52 (Java 8).

При повторной **полной** Gradle-сборке использовать исходники этого пакета и зависимости для GTNH 2.8.4; не называть исходный smoke на более новой GT5U доказательством совместимости 2.8.4.

## Граница проверки

**Самая важная нерешённая проверка — успешный запуск в полной GTNH 2.8.4 и успешное применение всех обязательных `@Inject`/`@Redirect` в её GT5U.** Зависимости и version guards исправлены; совместимость всех Mixin targets и поведения с более ранним GT5U не доказана. При несовпадении target FML/Mixin должен выдать явную ошибку, а не молча выключать загрязнение.

Не устанавливать на основной мир без smoke на копии. Если после правки остаётся crash, нужен **первый `Caused by` из `latest.log` / `fml-client-latest.log`**.
